# نظام الإدارة المالية الشامل (Finance Management System) 📊💡

مرحباً بك في المستودع الرسمي لـ **تطبيق الإدارة المالية (Finance App)**.
تم بناء هذا المشروع ليكون نظاماً متكاملاً وشاملاً يجمع بين إدارة المصاريف والإيرادات الشهرية، وبين التقارير المالية والتحليلات السنوية، ليمثل أداة قوية ودقيقة لتتبع الأموال وإدارتها باحترافية عالية.

## 🌟 فكرة المشروع (The Concept)

جاءت فكرة هذا التطبيق كدمج وتطوير لنجاح نظامين ماليين سابقين (نظام للإدخال الشهري ونظام للتقارير السنوية). 
يهدف التطبيق المدمج إلى تبسيط عملية الإدخال المالي اليومي والشهري، وفي نفس الوقت توفير لوحة تحكم (Dashboard) شاملة تعطي نظرة عامة ودقيقة للوضع المالي على مدار الأشهر والسنين. النظام مصمم ليكون مساعدك المالي الذكي الذي يحافظ على دقة أرقامك.

## ✨ أبرز مميزات النظام (Key Features)

- 📱 **تصميم مخصص للهواتف (Mobile-First):** واجهة مستخدم عصرية، سلسة، ومرنة، مصممة خصيصاً لتعمل بأفضل أداء على شاشات الهواتف الذكية لتسجيل المصاريف أينما كنت.
- 💰 **إدارة شهرية دقيقة:** نظام سهل لتسجيل الإيرادات والمصروفات الشهرية وتصنيفها بكل وضوح وبدون تعقيد.
- 📈 **تقارير سنوية وتحليلات شاملة:** استعراض متقدم للبيانات المالية على مدار السنين، مما يسهل عملية اتخاذ القرارات وإدارة الأموال بدقة.
- 🔔 **تقارير تلقائية:** نظام يدعم توليد التقارير المالية وإرسال ملخصات شهرية عبر الإيميل لتبقى على اطلاع دائم.
- 🔒 **أمان وسلامة البيانات المطلقة:** قاعدة بيانات قوية وآمنة (Supabase)، مبنية على هيكلة SQL صارمة ومحددة مسبقاً، لضمان عدم فقدان أو تغيير أي بيانات مالية حساسة تحت أي ظرف.

## 💻 التطوير والتقنيات (Tech Stack)

تم تطوير هذا النظام ليكون حديثاً وسريعاً، معتمداً على أفضل التقنيات لضمان تجربة مستخدم ممتازة:
- **الواجهة الأمامية (Frontend):** واجهة عصرية وسريعة الاستجابة، تم إنشاؤها عبر منصة [Lovable](https://lovable.dev).
- **قاعدة البيانات (Backend):** تكامل تام مع `Supabase`، مع هيكلة `SQL` دقيقة جداً مخصصة للحفاظ على سلامة واستقرار العمليات المالية.

### التشغيل المحلي (Local Development)

للبدء في تشغيل وتطوير المشروع على بيئتك المحلية:

```sh
# استنساخ المستودع
git clone https://github.com/ahmad00haddad/finance-app.git
cd finance-app

# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev
```
